Welcome to ArcVault

ArcVault is a user-friendly backup orchestration system for managing distributed backups across multiple machines.

Installation Overview

This installer will guide you through setting up ArcVault on your macOS system. You can choose to install:

  • Coordinator — The central server that manages and orchestrates backups
  • Agent — Client software that runs backups on machines
  • Both — Complete installation for a standalone setup

System Requirements

  • macOS 10.13 or later
  • Administrator access for installation
  • Internet connection for initial setup

What Happens Next

  1. Select components to install
  2. Choose installation location (default: /Applications/ArcVault)
  3. Configure your ArcVault installation
  4. Review settings and install
  5. Services will start automatically and open the dashboard in your browser
