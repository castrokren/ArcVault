Sync Flags Component Design

How should sync flags be integrated into the Jobs creation form?

A

Inline in Form

All sync flags as form fields below schedule

Add controls directly to the form: Mirror checkbox, Max Age input, Min Age input, Max Size input, Exclude Files/Dirs text areas. Simple and straightforward.

Pros: Discoverable, no extra clicks
Cons: Makes form longer, most users won't use all options

B

Collapsible "Advanced" Section

Hidden by default, expand to reveal sync flags

Add a collapsible section after Schedule labeled "Advanced Options" that expands to show Mirror, age filters, size limit, and exclusion patterns.

Pros: Keeps form clean, power users find it
Cons: One extra click, less discoverable

C

Separate Modal Dialog

Link/button "Configure Sync Options" opens a dedicated modal

Add a "Configure Sync Options" button in the form that opens a full-screen or large modal with all sync flags, validation, and preview of generated commands.

Pros: Space for detailed UX, room to show command preview
Cons: Most users won't open it, feels heavy

D

Tabs (Basic | Advanced)

Tab switcher within the form card

Keep basic fields (name, paths, schedule) on "Basic" tab. Add "Advanced" tab with sync flags. Similar to ScheduleBuilder pattern in your codebase.

Pros: Organized, familiar pattern, discoverable
Cons: Extra UI complexity, tabs feel formal
